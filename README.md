# 考研单词背诵系统

一个本地运行的考研英语单词背诵 Web 应用。后端 Python + SQLite，前端零依赖原生 JS，支持白/夜双主题。

## 运行环境

**整个项目 0 第三方依赖**，不需要 `pip install` 任何东西 —— 装好 Python 就能跑。

| 项目 | 说明 |
|---|---|
| 开发/测试所用版本 | **Python 3.13.5** |
| 支持范围 | **Python 3.9 – 3.13**（下限 3.9） |
| 实测通过 | **3.9.13 / 3.11.15 / 3.13.5** 三个版本上，全部接口与前端流程实测正常 |
| 第三方依赖 | **无**。HTTP 层用自带的 `liteweb.py`（纯标准库 `http.server`），数据库用标准库 `sqlite3` |
| 操作系统 | 主要面向 Windows（`start.bat`）；`python app.py` 在 macOS / Linux 上同样可用 |

用到的标准库：`http.server`、`sqlite3`、`csv`、`json`、`urllib`、`threading`、`datetime`、`math`、`re`、`os`、`sys`、`mimetypes`、`ast`。

> **为什么不用 Flask**：早期版本依赖 Flask，结果在一台有多个 Python 的机器上，
> 双击 `start.bat` 解析到的解释器没装 Flask，直接 `ModuleNotFoundError`。
> 现在 HTTP 层改成标准库实现（`liteweb.py`，Flask 子集 API），这类问题彻底消失，
> 顺带把支持的版本下限从「装了 Flask 的 3.9+」放宽到「任何 3.9+」。
>
> 没有用任何 3.9 以上才有的语法（`match`、`X | Y` 类型的 isinstance、`removeprefix`、
> `except*`、`tomllib` 都没碰）；3.9 是实测下限，**不承诺 3.8 及更低版本**。

## 快速开始

```bash
cd kaoyan-vocab
python fetch_data.py      # 首次：下载第三方数据（音标 / 词典 / 例句，约 74 MB）
python import_data.py     # 建库：词表 + 音标 + 词性释义 + 例句 → SQLite
python app.py             # 启动，浏览器打开 http://127.0.0.1:5178
```

仓库里只带了词表本体（`data/vocab-source.csv`，324 KB）；音标、词典、例句这三个
第三方大文件共约 74 MB，用 `fetch_data.py` 拉取（纯标准库、带进度条、可重跑跳过已下载的）。
不想跑脚本的话，也可以按「词库来源」一节的链接手动下载后放进 `data/`。

Windows 上双击 `start.bat` 也可以。`start.bat` 会自动挑选一个 **3.9 或更高**的
解释器（依次尝试 `py -3` → `python3` → `python`），启动时会打印实际用的是哪个：

```text
[解释器] py -3   版本 3.13.5
```

如果机器上有多个 Python 而双击启动报错，用最后那个「手动指定」的写法最省事：

```bat
"C:\Users\you\AppData\Local\Programs\Python\Python313\python.exe" -X utf8 app.py
```

## 词库来源

词表是仓库里的 `data/vocab-source.csv`（5398 词，324 KB），词频统计口径见该文件首部说明；
可读版本见 `docs/考研英语真题高频词汇表.md`。

- **音标**：[cmudict](https://github.com/cmusphinx/cmudict)（ARPAbet 转 IPA，离线，覆盖 5366/5398）
- **词性释义**：[ECDICT](https://github.com/skywind3000/ECDICT)（覆盖 5398/5398）——每个词按词性分行列出释义，例如
  `abandon` → 及物动 放弃、抛弃、遗弃 ｜ 名 放任、无拘束、狂热
- **英式音标与真人发音**：单词首次出现时按需从 [dictionaryapi.dev](https://dictionaryapi.dev) 拉取并永久缓存到本地；拉不到时自动回退到浏览器语音合成，完全离线也能发音。

> ECDICT 数据按 CC BY-SA 3.0 共享。首次建库会流式扫描 `data/ecdict.csv`（66 MB）并只保留需要的 5398 词，
> 建库完成后该文件可以删除；需要重建词性释义时再放回来重跑 `import_data.py` 即可（学习进度不受影响）。

## 词性释义

ECDICT 的释义天然按词性分行，导入时解析成结构化数据存进 `words.pos_json`：

```json
[{"pos":"vt","pos_zh":"及物动词","kind":"pos","senses":["放弃","抛弃","遗弃"]},
 {"pos":"n","pos_zh":"名词","kind":"pos","senses":["放任","无拘束","狂热"]},
 {"pos":"","pos_zh":"专业","kind":"domain","domain":"计","domain_zh":"计算机","senses":["属性"]}]
```

**词性用全称**，不写「名」「形」这类缩写：名词 / 动词 / 及物动词 / 不及物动词 /
形容词 / 副词 / 介词 / 连词 / 代词 / 数词 / 冠词 / 感叹词 / 助动词 / 复数 …
词典里的专业领域标记同样展开，`[计]` 显示为「专业·计算机」。

**长释义可展开**：义项多的词（如 `turn` 有 12 个义项）默认只显示前几个，后面跟一个
可点击的「展开全部 N 义」——点一下**在原地展开完整释义**（不换页、不弹窗，再点收起）：

- 学习卡揭开答案后按词性分行显示，每行默认 4 个义项
- 详情弹窗每行默认 8 个义项
- 每个词性最多保留 12 个义项（再多对背单词没有意义），**展开看到的就是全部**
- 主词性优先取 ECDICT 的 `pos` 占比，没有占比时按词典自身的排列顺序取第一个
- 设置页可以整体关闭词性释义；词库搜索也支持按释义内容命中

展示效果（学习卡上的样子）：

```text
turn  /tɜːn/

名词      转弯、转动、旋转、翻转  展开全部 12 义
及物动词  使旋转、转弯、转动、使转向  展开全部 12 义
不及物动词 转动、转弯、转向、翻转  展开全部 12 义
```

## 例句

数据来源是 [Tatoeba](https://tatoeba.org/) 的英汉句对（经 [manythings.org](https://www.manythings.org/anki/) 打包，
约 3.2 万对，CC-BY 2.0 FR），导入时给每个词挑 1-3 条**短句**：

- 句子按长度升序建索引，取每个词形最靠前的候选 —— 也就是「最短、最自然」的那几条
- 只认真正属于该词的词形变化（`abandon` 会匹配 `abandoned`，但不会匹配 `abandonment`）
- 挑中的词形一并存下来，前端据此**精确高亮**，不是拿词根去乱匹配
- 学习卡显示 2 条，详情弹窗显示 3 条；没有英汉对照句时回退到词典的英文例句

覆盖率（3496 / 5398 词有例句）：

| 梯队 | 覆盖率 |
|---|---:|
| 核心高频 | **93%** |
| 高频 | 75% |
| 常见 | 54% |
| 一般 | 39% |

高频词覆盖得最好 —— 这正好是最需要例句的那一档。

### 繁简转换

原始语料里约 **44%** 的译文是繁体（`她們`、`這棟`、`湯姆`）。直接展示给考研学生很别扭，
所以项目里带了一张人工核对的繁简对照表 `trad2simp.py`（618 对），导入时逐字转换。

表的做法：先收常用繁体字，再用「语料里出现但不在表内」的字符清单逐字复核补齐 ——
这样能发现手误（例如把 `業业` 打成了 `业业`）。最后剩下没转的只有同形字（我 / 你 / 的 / 是 …）。

```text
她們被母親拋棄了。        ->  她们被母亲抛弃了。
這棟老房子被拆除了。       ->  这栋老房子被拆除了。
他设法及时到達那里了。      ->  他设法及时到达那里了。
```

## 核心机制

### 三轮制

每个单词默认要过 3 轮，**上一轮毕业才解锁下一轮**（轮数可在设置里改）：

| 轮次 | 形式 | 说明 |
|---|---|---|
| 第 1 轮 · 识记 | 看英文 → 认中文 | 建立音形义的第一印象 |
| 第 2 轮 · 拼写 | 看中文 → 拼英文 | 从「认得」变成「写得出来」 |
| 第 3 轮 · 运用 | 真题搭配挖空 → 填词 | 放到真实语境里回忆 |

某一轮的间隔达到该轮的毕业天数（默认 3 / 7 / 21 天）就算毕业，系统立刻创建下一轮的卡片并放进复习队列。最后一轮毕业 = 这个词彻底完成。

### 间隔重复（复合遗忘曲线）

每一轮内部用 SM-2 变体调度：

- 四个评级：忘了 / 模糊 / 记得 / 简单，对应 SM-2 的 q = 2 / 3 / 4 / 5
- ease 因子初始 2.5，范围 1.3 – 3.2
- 间隔阶梯：首次答对 1 天 → 3 天 → 之后按「间隔 × ease」增长
- 轮次修正：轮次越高（回忆比识记难），同样评级下间隔收紧（0.85 / 0.7 倍）
- 忘了 → ease 下调、连对清零、10 分钟后在本次会话里重来

遗忘曲线用指数模型 R(t) = e^(−t/S)，S 即该词当前的间隔天数。仪表板里的曲线就是按各轮实际平均 S 画出来的。

### 倒计时与每日计划

- 显示距考试的天数（默认 2026-12-19，即 2027 考研初试，可改）
- 每天需要学多少新词 = 剩余未学词数 ÷ 剩余天数（向上取整）
- 同时给出待完成轮次、日均轮次负荷等参考值

### 词库卫生

- 考纲里 200 个词频为 0 的词被单独核查过，其中 38 个其实是词形还原误判（实际考过，已补录）
- 190 个基础功能词（the / of / and / be …）默认不进入新词队列，可在设置里打开

## 功能一览

- **背新词 / 复习**：卡片式，支持空格翻面、1-4 评级、A 发音、S 收藏
- **音频与音标**：美音/英音音标常显，喇叭按钮真人发音，回退浏览器合成音
- **助记**：自动做词根词缀拆解（前缀 + 词根 + 后缀），附同根词族、形近词、真题搭配；也可以自己写笔记
- **仪表板**：总览、26 周学习热力图、遗忘曲线、未来 30 天复习量预测、各梯队进度、最难记的 15 个词、近 14 天记录
- **词库**：按梯队/状态筛选，搜索单词、释义、搭配；点开看完整卡片
- **设置**：考试日期、轮数、毕业间隔、每批卡片数、参与学习的梯队、语速、导出 JSON、清空数据

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/bootstrap` | 设置、统计、倒计时计划 |
| GET | `/api/session?mode=mix\|new\|review&limit=N` | 取一批卡片 |
| POST | `/api/answer` | 提交评级，返回下次间隔 |
| GET | `/api/word/<id>` | 单词详情：词性释义 + 例句 + 助记 + 同根词 + 形近词 |
| POST | `/api/note` | 保存笔记 / 收藏 |
| GET | `/api/dashboard` | 仪表板全部数据 |
| GET | `/api/browse` | 分页检索词库 |
| POST | `/api/enrich/<id>` | 拉取英式音标与真人发音 |
| GET/POST | `/api/settings` | 读写设置 |
| GET | `/api/export` | 导出学习记录 |
| POST | `/api/reset` | 清空进度 / 全部数据 |

## 移动端

响应式断点 720px（另有 380px 的紧凑档）。窄屏下的处理：

- 侧栏收成抽屉，点右上角按钮展开，**点遮罩或切页自动收起**
- 倒计时区改单列，六个数字指标排成两列；进度环缩到 84px
- 学习卡内边距 40/42 → 20/16，单词字号 46 → 32px（380px 以下再降到 28px）
- 学习热力图格子 11 → 9px，26 周合计 292px，360px 屏也放得下，不用横向滚
- 词性标签允许换行到释义上方；词库表格保持横向滚动
- 评级按钮 4 列收紧间距

> 测试方法记一笔：Chrome headless 的 `--window-size` 有约 500px 的下限，
> 想量 360/390px 的真实布局，得把页面塞进对应宽度的 iframe 里再读 `scrollWidth`。
> 另外 CSS 的 `@media` **不提升优先级**，移动端规则必须写在文件最后，
> 否则同等特异性的桌面规则会因为「后出现者胜」把响应式全部盖掉（这个坑踩过一次）。

├─ app.py            后端：路由与 11 个 API（业务逻辑都在这）

├─ mnemonic.py       词根词缀助记引擎
├─ ecdict.py         ECDICT 词性释义解析（流式扫描 66MB CSV）

├─ trad2simp.py      繁简对照表（618 对，导入时把繁体译文转简体）

│  ├─ cmudict.dict      音标源数据（3.6 MB，fetch_data.py 下载）
│  ├─ ecdict.csv        词性释义源数据（66 MB，下载）
│  └─ cmn.txt           英汉句对源数据（4.6 MB，下载）
